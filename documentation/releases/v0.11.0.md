# Version 0.11.0 — Hub central et navigation unifiée

Cette version transforme l’accès au module avec un nouvel écran d’accueil illustré servant de hub central.

## Nouveautés

- accès unique au plateau, à la collection, aux decks, aux boosters, au règlement et au glossaire ;
- tableau d’équilibrage accessible depuis le hub pour les MJ ;
- boutons de retour à l’accueil dans les interfaces principales ;
- carrousel horizontal pour les sortilèges événementiels possédés ;
- règlement réécrit avec un intitulé distinct pour chaque règle ;
- suppression des anciennes commandes de chat ;
- README entièrement réorganisé autour des fonctionnalités disponibles.
