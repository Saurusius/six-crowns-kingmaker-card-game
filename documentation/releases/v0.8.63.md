# Version 0.8.63 — Constructeur de deck aéré

## Changements

- L’analyse du deck n’occupe plus aucune place dans le constructeur principal.
- Un bouton **Analyser le deck** ouvre une fenêtre indépendante présentant la courbe de force, les lignes, les raretés, les types et les capacités.
- La fenêtre d’analyse se met à jour lorsque la composition du deck change.
- Le panneau **Deck actuel** contient désormais le nom du deck, la sélection des decks enregistrés et toutes les actions de gestion.
- La validation du deck est résumée directement dans le panneau latéral.
- Toute la hauteur disponible est rendue à la mosaïque des cartes.

## Vérifications recommandées dans Foundry

1. Ouvrir le constructeur et vérifier que la mosaïque commence juste sous les filtres.
2. Nommer un deck, le sauvegarder, le renommer puis le dupliquer depuis le panneau de droite.
3. Ouvrir l’analyse, ajouter ou retirer une carte et vérifier que la fenêtre se met à jour.
4. Redimensionner le constructeur pour contrôler le passage du panneau latéral sous la mosaïque sur une petite fenêtre.
