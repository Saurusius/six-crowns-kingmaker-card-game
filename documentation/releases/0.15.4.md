# 0.15.4 — Lisibilité des sortilèges

- Les descriptions trop longues dans la sélection des sortilèges défilent désormais automatiquement et lentement.
- L’animation n’est ajoutée que lorsqu’un débordement est détecté.
- La vitesse est adaptée à la longueur du texte afin de conserver une lecture confortable.
