# Le Jeu des Six Couronnes v0.10.21

## Correctif de chargement et réparation des macros

Cette version rétablit les fenêtres principales du module et sécurise leur initialisation.

### Correctifs

- correction de l’import invalide du règlement qui bloquait le plateau, la collection et le constructeur de deck ;
- isolation des données du règlement dans un module indépendant ;
- réparation et mise à jour automatiques des macros existantes au démarrage du monde ;
- ajout de la macro **Jouer au Jeu des Six Couronnes** ;
- messages d’erreur explicites lorsque le module ou son API ne sont pas disponibles ;
- séparation des étapes d’initialisation afin qu’une erreur locale ne bloque plus les autres outils.

### Installation

Remplacez l’ancienne version du module, puis rechargez le monde avec un compte MJ afin de mettre les macros à jour.
