# Le Jeu des Six Couronnes v0.10.0

## Sortilèges événementiels — Terres Dérobées

Cette version introduit la première suite de cartes événementielles dorées et une nouvelle phase secrète avant le début de la partie.

### Nouveautés

- sélection secrète d’un sortilège après le choix des decks et avant le lancer de pièce ;
- un seul sortilège équipé et une seule activation par joueur et par partie ;
- cinq cartes dorées : **Et là, un ours !**, **Une bonne bière**, **Sauvetage de sac**, **Chancla de titane** et **Hydre vorace** ;
- ciblage interactif, révélation animée et état **Utilisé** sur le plateau ;
- adversaire automatisé capable d’équiper et d’activer ses propres sortilèges ;
- booster événementiel contenant exactement une carte dorée ;
- ajout de l’**Ours des Terres Dérobées** comme invocation technique non collectionnable ;
- catalogue porté à 165 cartes collectionnables.

### Installation

Installez le module avec l’URL du manifeste disponible dans le README ou téléchargez l’archive attachée à cette release.
