# Le Jeu des Six Couronnes v0.10.1

## Confort et mise en scène des sortilèges

Cette version améliore la préparation des parties et la lisibilité des cartes événementielles.

### Améliorations

- ordre de préparation clarifié : **decks → sortilège → lancer de pièce** ;
- seuls les sortilèges réellement possédés sont proposés, sans révéler les cartes manquantes ;
- révélation des effets maintenue jusqu’à dix secondes, avec fermeture anticipée possible ;
- apparition centrale renforcée des sortilèges pendant une partie ;
- booster événementiel mono-carte recentré avec une animation dorée dédiée ;
- remplacement de **Agrandir les options** par **Afficher les options** ;
- maintien permanent du bouton **Vue compacte / Vue détaillée** ;
- extension de la suite automatisée à 138 tests.

### Installation

Installez le module avec l’URL du manifeste disponible dans le README ou téléchargez l’archive attachée à cette release.
