# Le Jeu des Six Couronnes v0.10.22

## Plateau épuré, règlement réparé et macros fiabilisées

Cette version corrective nettoie l’interface de partie et consolide les raccourcis du module.

### Correctifs

- suppression de l’encart **État de la manche** dans le panneau latéral ;
- suppression du **Journal de partie** dans l’interface ;
- ouverture du **Règlement** dans une fenêtre modale dédiée, sur le même modèle que le glossaire ;
- création ou mise à jour automatique des quatre macros principales ;
- ajout d’une API de secours et d’une gestion d’erreur lisible dans les macros ;
- vérification des permissions d’exécution pour les joueurs autorisés.

### Macros concernées

- **Jouer au Jeu des Six Couronnes** ;
- **Ma collection** ;
- **Constructeur de deck** ;
- **Ouvrir un booster**.

### Installation

Installez le module avec l’URL du manifeste disponible dans le README ou téléchargez l’archive attachée à cette release. Rechargez ensuite le monde avec un compte MJ pour actualiser les macros existantes.
