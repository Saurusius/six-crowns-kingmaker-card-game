# Le Jeu des Six Couronnes v0.10.2

## Lisibilité du jeu et ergonomie des collections

Cette version consolide l’interface des cartes, du glossaire, de la collection et du constructeur de deck.

### Améliorations

- meilleure lisibilité des traits et des lignes pendant le choix de la main de départ ;
- prévisualisation du sortilège équipé pendant les parties ;
- distinction claire entre **Unités**, **Sortilèges** et **Invocations** dans le glossaire ;
- règlement ouvert dans une fenêtre dédiée ;
- ajout d’une vue carrousel dans le constructeur de deck ;
- maintien des options essentielles de collection lorsque les panneaux secondaires sont réduits ;
- suppression de la prévisualisation automatique au survol dans la collection ;
- bordures de cartes adaptées à leur collection et à leur rareté.

### Installation

Installez le module avec l’URL du manifeste disponible dans le README ou téléchargez l’archive attachée à cette release.
