# Version 0.8.61 — Interface de préparation enrichie

Cette version corrige et modernise plusieurs écrans très utilisés :

- constructeur de deck entièrement réorganisé en mosaïque ;
- filtres regroupés dans un panneau responsive sans débordement ;
- icônes cohérentes dans le glossaire pour les types, lignes, raretés et capacités ;
- icône de rareté ajoutée dans les pastilles colorées de la collection ;
- écran de préparation et tirage au sort enrichi avec décor, particules et pièce 3D améliorée ;
- sélection de la main simplifiée avec une coche verte ou une icône de remplacement rouge ;
- amélioration générale des retours à la ligne et des petits écrans.
