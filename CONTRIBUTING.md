# Contribuer

## Avant une proposition

- Exécuter `npm run check`.
- Ne pas ajouter d’illustration officielle, extraite d’un livre, d’un jeu vidéo ou d’un autre produit sans autorisation explicite.
- Garder les règles dans `scripts/rules/` et l’affichage dans `scripts/applications/`.
- Décrire les capacités de cartes avec des identifiants génériques réutilisables.

## Convention de commits

- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `data:` cartes et équilibrage
- `art:` illustrations et interface
- `docs:` documentation
- `test:` tests
- `release:` préparation d’une version
