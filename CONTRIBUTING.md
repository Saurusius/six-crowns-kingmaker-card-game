# Contribuer

Les corrections ciblées et reproductibles sont les bienvenues.

- Créez une branche dédiée.
- Décrivez le problème et le comportement attendu.
- Conservez la compatibilité Foundry VTT 14.
- Ajoutez ou adaptez un test lorsqu’une règle, une transaction ou un booster change.
- Lancez `npm run check` avant la pull request.
- N’ajoutez pas d’illustration sans vérifier ses droits, son format et ses dimensions.
